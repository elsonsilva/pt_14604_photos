Sobre o Projeto

Este projeto foi desenvolvido como solução para a Questão 3 da produção temática.

Trata-se de uma aplicação Angular 16 que utiliza componentes standalone e signals para gerenciamento de estado. A aplicação permite visualizar, adicionar, editar e excluir fotos obtidas da API JSONPlaceholder.

Pela falta de acesso público à biblioteca sidsc-componets, optei por utilizar o angular material.

A API JSONPlaceholder contém dados de url de photos, mas as mesmas não estão disponíveis. Dessa forma não é possível visualizar as photos provenientes da API, mas a aplicação permite exibir ao menos os títulos dessas photos. Caso o usuário faça o upload de uma imagem, ela será exibida na galeria.

Para não ter que criar todo um banco de dados para armazenar as fotos, utilizei o cache local do navegador para persistir os dados e simualar um crud na API.

Tecnologias utilizadas:

  • Angular 16
  • Angular Material
  • RxJS para manipulação de observables
  • Cache local no navegador para persistência de dados
  • Signals para gerenciamento de estado
